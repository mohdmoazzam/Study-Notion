# Feature ideas

A backlog of features for StudyNotion, grouped by who benefits. Each file explains why the
feature matters, its rough scope, and which parts of the code it touches.

| File | What's in it |
|---|---|
| [01-fix-first.md](01-fix-first.md) | Gaps that already affect users today |
| [02-students.md](02-students.md) | Learning and buying experience |
| [03-instructors.md](03-instructors.md) | Tools for course creators |
| [04-super-admin.md](04-super-admin.md) | New sections for the super admin console |
| [05-platform.md](05-platform.md) | Cross-cutting quality, security and infrastructure |

## Suggested order

1. **Working emails** and **payment webhooks** ([01](01-fix-first.md)): accounts and money depend on them.
2. **Platform commission** and **revenue dashboard** ([04](04-super-admin.md)): make the platform viable as a business.
3. **Certificates** and **search with filters** ([02](02-students.md)): the student-facing features people notice most.
4. Everything else, in whatever order matches user feedback.

## Status key

Each feature has a status line you can update as work progresses:
`Idea` → `Planned` → `In progress` → `Done`.
